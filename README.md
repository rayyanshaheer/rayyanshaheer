CS student at FAST NUCES and full-stack software engineer building web apps, APIs, automation tools, and cloud-backed systems.

I like backend-heavy products, clean deployment workflows, and practical AI/ML or automation use cases. Most of my projects start from a real problem, then turn into something maintainable enough to use and improve.

## 💫 About Me

- CS student, Class of 2027.
- Freelance full-stack developer working on web apps, APIs, dashboards, and automation tools.
- Interested in backend engineering, cloud computing, DevOps, scalable systems, and practical AI.
- I enjoy building useful software more than chasing random tech stacks.

## 🔭 What I Work On

- Full-stack web apps with React, Node.js, FastAPI, PostgreSQL, and Supabase.
- Backend APIs, dashboards, admin portals, and automation tools.
- Cloud and DevOps workflows with AWS, Docker, GitHub Actions, and serverless tools.
- Python scripts for scraping, testing, data collection, and workflow automation.
- AI/ML and IoT projects where software helps with real decisions.

## 🧩 Project Areas

- Smart systems that connect sensors, dashboards, APIs, and prediction models.
- Verification platforms for certificates, events, and student workflows.
- Admin systems for registrations, documents, job fairs, and internal operations.
- Automation tools that reduce manual work in data collection, testing, and reporting.
- Mobile and web products with clean backend architecture behind them.

## 🛠️ How I Build

- I care about readable code, simple architecture, and clear API contracts.
- I think about deployment, environment variables, database design, and maintenance early.
- I prefer projects that can be used, tested, and improved over time.
- I keep the stack practical for the problem, not impressive for no reason.
